# Second-assistant options and student offers

Official pages checked October 24, 2026. This document records research and a prepared handoff. It does not create an account, subscribe, claim an offer, install an agent, connect credentials or schedule work.

## Recommendation

For one paid assistant responsible for independent creative research, rendered alternatives, website work and recurring execution, **Claude Pro at $20/month** is the best feature fit among the options checked. This is a recommendation about the available workflow, not proof that its designs or growth results will outperform another model. Test it against `docs/creative-lead-assignment.md`.

The current Pro plan includes Research, Claude Design, Claude Code and scheduled cloud tasks. The scheduled-task documentation says new cloud tasks can run with the device asleep or app closed; tasks requiring local apps/files, and some older tasks, can still be local. Account availability and connectors must be checked during setup. Pro has session/weekly usage limits shared across features; it is not unlimited agency capacity. Pro does not include developer API usage. Keep additional usage off unless a separate budget is agreed.

Anthropic's official Pro support page states there is **no standard individual-plan discount**. Education is an institution-wide offering, not an automatic personal Pro discount for everyone with a university email. A university-provided chat model does not establish access to the Claude app, Code, Design or cloud scheduling.

## Verified alternatives

| Option | Listed offer | Useful role | Actual limitation |
| --- | --- | --- | --- |
| Claude Pro | $20/month, or $200 billed annually | Research/creative lead, design, code, recurring cloud work | Usage limits, account/connector setup; API billed separately |
| Google AI Pro student offer | 12 months at no charge after eligibility verification | Research, visual concepts and an independent review | Personal Google account, age 18+, enrollment verification and payment required; eligible U.S. college students can apply; renews at the applicable paid price |
| Kiro for Students | 1,000 Kiro credits/month for 12 months; University of Florida is listed | Website/repository implementation helper | Coding-focused; not a complete marketing/creative lead or established 24/7 research service |
| UF NaviGator AI | University-provided tools for UF users | Campus chat, guided assistants and toolkit; research/brainstorming where appropriate | UF sign-in/terms apply; exact model entitlements and external-business use not verified; not a confirmed personal Claude Pro account |
| GitHub Copilot Student | Free after student verification | Additional repository coding assistance | Current Student access uses auto model selection; do not promise selection of Claude or free Claude Pro/Code |
| Grok Bot | Current new-customer Premium plan $30/month | X/public-topic research, private bookmarks after X connection, routines | Separate account/setup and usage limits; not a native connection to this Codex chat |

Google's current student page says redeem by **December 31, 2026**; qualifying students can receive 12 months free. The page lists renewal at **$19.99/month** after that period. Use a personal Google account and verify enrollment through the official flow, not a school-managed Workspace account. Eligibility is determined by the provider; no student documents belong in chat or the public repository.

Kiro's terms require age 18+, current enrollment, an account with a participating university email, and verification if requested. UF appears in the published eligible-school list. Credits do not roll over, additional credits cannot be purchased during the benefit period, and the account falls back to Free Tier limits after the benefit ends. This is not an auto-renewing paid plan according to those program terms.

Neither the Google nor Kiro offer requires the GitHub Student Developer Pack. The Pack is a separate optional application; it is unnecessary to complete it before trying those offers.

Canva's free Education offering is primarily K–12 and is not a blanket free Pro entitlement for a college student. College access may be through an institution's Canva Campus arrangement, which was not verified for UF. Claude Design can hand assets to connected creative tools, but their account/plan entitlements are separate.

## What has been prepared

`CLAUDE.md` gives an incoming Claude/code agent the actual Cancha context. `docs/creative-lead-assignment.md` specifies a first benchmark with real sources, three rendered directions, a finished carousel, a video storyboard, a small website improvement and a measurable growth experiment. Existing production constraints, forms, source checks and receipts are preserved.

After account authorization, the selected assistant can run its own task and exchange artifacts/branches through the repository. This Codex conversation does not run continuously or automatically receive another app's messages. A recurring assistant workflow and its authenticated handoff must be configured and tested; none is active from this documentation change.
